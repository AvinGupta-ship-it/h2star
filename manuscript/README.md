# Manuscript

`main.tex` is the preprint source (Elsevier `elsarticle` class; primary
venue *Adsorption* per the pre-registered fork rule — see
`docs/validation_plan.md`, Gate E2).

Every number in the text is a macro from `generated_numbers.tex`, which is
machine-written by `scripts/reproduce_paper.py` from the committed analysis
records. **Never edit `generated_numbers.tex` by hand.**
`tests/test_manuscript_numbers.py` fails if the committed macro file
disagrees with a regeneration.

Build:

```sh
# Debian/Ubuntu: apt install texlive texlive-publishers texlive-latex-extra latexmk
cd manuscript && latexmk -pdf main.tex
```

Figures are included from `../figures/v1/` (committed, regenerated by
`scripts/make_figures_v1.py`).
